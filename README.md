## 🚀 Featured Projects

### 🏠 PGPilot — Commute-Aware PG Discovery Platform

**Full-stack web application · Live project**

A location-aware accommodation discovery platform that helps users explore real PG listings and choose stays based on their daily commute and preferences.

- Integrates **Google Places API**, interactive maps, and **route-based commute estimation**.
- Uses **explainable Smart Match ranking** with adjustable preference weights, ratings, distance, and travel time.
- Supports authentication, user profiles, favorites, feedback, comparison, and search history.
- Uses **Neon PostgreSQL** and a containerized Node.js backend.
- Deploys through **Docker + GitHub Actions CI/CD + Azure Container Apps**, with a **Vercel** frontend; Render has also been tested as a backup.

**Stack:** React · Tailwind CSS · Node.js · Express · PostgreSQL · JWT · Docker · Azure · GitHub Actions · Google Places · OpenRouteService

[Explore project on my portfolio](https://aaquil-16.github.io/Mohammed-Aaquil-A-Portfolio-/)

### 📚 StudySpotVIT — Intelligent Library Seat Recommendation

**IoT + Android · IEEE conference paper**

A smart library seating framework that combines live occupancy sensing and noise monitoring to help students identify suitable study spaces.

- Built an **ESP32-based seat-monitoring prototype** with occupancy and sound sensors.
- Developed **Persistent Disruptive Noise Detection (PDND)** to distinguish sustained disturbance from brief noise spikes.
- Connected the hardware to **Firebase** for near-real-time updates.
- Created an **Android application** for seat availability, recommendations, and reservation workflows.

**Stack:** ESP32 · Embedded C · Android · Java · Firebase · IoT sensors

[Explore project on my portfolio](https://aaquil-16.github.io/Mohammed-Aaquil-A-Portfolio-/)
